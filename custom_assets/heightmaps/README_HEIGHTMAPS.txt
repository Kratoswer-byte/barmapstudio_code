# CARTELLA HEIGHTMAPS PERSONALI
Inserisci qui i tuoi file di altimetria (heightmap) personalizzati per le tue mappe di Beyond All Reason.

FORMATI CONSIGLIATI:
- PNG 16-bit Grayscale (Consigliato per massima fluidità delle rampe, 65.536 livelli di grigio)
- RAW 16-bit Unsigned Little-Endian
- PNG 8-bit / BMP (Supportati, ma soggetti a terrazzamenti su dislivelli elevati)

RISOLUZIONI CONSIGLIATE PER BAR (RECOIL ENGINE):
- 513 x 513 pixel  (Mappa 8x8 km - 1v1 / 2v2 rapido)
- 1025 x 1025 pixel (Mappa 16x16 km - Standard 8v8 competitivo)
- 1537 x 1537 pixel (Mappa 24x24 km)
- 2049 x 2049 pixel (Mappa 32x32 km - Grandi battaglie)
Nota: Risoluzioni arbitrarie (es. 1024x1024 o 2000x2000) vengono automaticamente ricampionate con filtro bicubico.
